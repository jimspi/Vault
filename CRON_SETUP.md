# Daily Automatic Insights - Cron Setup

Vault now includes automatic daily insight generation that runs at **7pm MST every day**.

## How It Works

The system automatically:
1. Checks which workspaces had activity that day (documents uploaded or manual insights created)
2. Generates 2-3 AI insights for each active workspace
3. Focuses on summarizing the day's content while considering all historical data
4. Creates actionable insights and reminders

## Setup Instructions

### 1. Configure Cron Secret

Add a secret key to protect the cron endpoint:

**In Vercel Dashboard:**
1. Go to your project → Settings → Environment Variables
2. Add variable:
   - Name: `CRON_SECRET`
   - Value: Generate a random secure string (e.g., `openssl rand -base64 32`)

3. Add variable:
   - Name: `SUPABASE_SERVICE_ROLE_KEY`
   - Value: Your Supabase service role key (found in Supabase dashboard → Project Settings → API)

### 2. Deploy

The cron job is configured in `vercel.json` and will automatically activate after deployment.

```json
{
  "crons": [
    {
      "path": "/api/cron/daily-insights",
      "schedule": "0 2 * * *"
    }
  ]
}
```

**Schedule:** `0 2 * * *` = 2am UTC daily
- **MST (Winter)**: 7pm MST (2am UTC next day)
- **MDT (Summer)**: 8pm MDT (2am UTC next day)

### 3. Verify

After deployment, check that the cron job is registered:
1. Go to Vercel Dashboard → Your Project → Settings → Cron Jobs
2. You should see `/api/cron/daily-insights` listed
3. Check execution logs in the Logs tab

## Features

### Smart Processing
- Only processes workspaces with activity that day
- Skips workspaces that already had daily insights generated
- Uses complete memory (all documents + insights) for context
- Prioritizes recent content while considering historical data

### Insight Types Generated
- **Patterns**: Themes across the day's content
- **Suggestions**: Next steps based on what was added
- **Reminders**: Important tasks or follow-ups
- **Trends**: Changes or developments over time
- **Contradictions**: Conflicting information to review

### Rate Limiting
- Automatic daily generation doesn't count against manual generation limits
- Each workspace can still manually generate 5 insights per day
- Daily auto-generation is marked with `auto_daily: true` in metadata

## Monitoring

### View Cron Execution Logs

**In Vercel Dashboard:**
1. Go to your project
2. Click "Logs" in the sidebar
3. Filter by `/api/cron/daily-insights`
4. Check for errors or successful executions

### Check Generated Insights

Insights generated by the daily cron will have:
- Status: `new`
- Metadata: `{ source: 'ai_generated', auto_daily: true }`

## Troubleshooting

### Cron not executing
1. Verify `CRON_SECRET` is set in Vercel environment variables
2. Check that cron jobs are enabled for your Vercel plan (Pro/Enterprise required for hobby projects)
3. Redeploy after adding environment variables

### No insights generated
1. Check that workspaces had activity that day (documents or manual insights)
2. Verify `SUPABASE_SERVICE_ROLE_KEY` is correctly set
3. Check Vercel logs for error messages
4. Ensure workspaces have content to analyze

### Wrong time execution
The cron runs at 2am UTC which is:
- 7pm MST (November - March)
- 8pm MDT (March - November)

This is due to Mountain Time observing Daylight Saving Time. You can adjust the schedule in `vercel.json` if needed.

## Disabling Daily Insights

To disable automatic daily insights:
1. Remove the cron configuration from `vercel.json`
2. Redeploy

Or keep the cron but add a feature flag in the workspace settings.

## Cost Considerations

- Each daily execution processes all active workspaces
- Uses AI API calls (Claude/OpenAI) per workspace
- Monitor your AI API usage if you have many active workspaces
- Consider adding workspace-level opt-in/opt-out for daily insights

## 🚀 Demo Setup Instructions

### Step 1: Upload the Documents

1. **Go to your Vault app:** https://vault-mm8poh86a-jimspis-projects.vercel.app/dashboard
2. **Click the "Upload" tab**
3. **Upload both documents:**
   - Drag and drop `Product_Strategy_Q1_2024.txt`
   - Drag and drop `User_Research_Findings_December_2023.txt`
4. **Wait for processing** (should be instant since we fixed the processing issue!)
5. **Verify** both documents show status "ready" in the Documents tab

### Step 2: Add the Sample Insights Manually

1. **Click the "Insights" tab**
2. **Click "Create Insight" button**
3. **Open `SAMPLE_INSIGHTS_TO_ADD.md`**
4. **Copy and paste each insight:**
   - Select the **Type** (Pattern/Contradiction/Suggestion/Trend)
   - Paste the **Title**
   - Paste the **Content**
   - Click **"Create"**
5. **Repeat for all 4 insights**

### Step 3: Test AI Insight Generation

1. **Go back to the Dashboard or Documents tab**
2. **Click "Generate AI Insights"**
3. **Watch the beautiful animated overlay**
4. **Check the Insights tab** to see AI-generated insights alongside your manual ones

## 🚨 Troubleshooting

**If documents show "processing" forever:**
- This was fixed in the latest deployment
- Refresh the page - they should show "ready"

**If insights fail to create:**
- Make sure you ran the database migration SQL
- Check the browser console for error details

**If AI generation fails:**
- Ensure you have the OpenAI API key set in Vercel
- Check that you haven't hit the daily limit (5 generations/day)
